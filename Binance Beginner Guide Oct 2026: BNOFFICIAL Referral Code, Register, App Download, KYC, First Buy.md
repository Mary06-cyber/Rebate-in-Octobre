## 4. Do new users need KYC?

Yes.

Without identity verification, deposit, spot trading, P2P and withdrawals are usually limited.

KYC flow:
- Select country / region
- Select document type
- Upload ID
- Face check
- Wait for review

Name must match the document exactly.

---

## 5. Why KYC fails

Common reasons:
- Blurry photo
- Glare
- Missing corners
- Wrong name spelling
- Expired ID
- Mask / hat / glasses
- Dark room
- Camera permission off
- Filters
- Too many failed attempts

Fix:
1. Match account info with ID
2. Flat surface, good light
3. No glare
4. Full corners visible
5. Enable camera
6. No mask/filter
7. Update app
8. Resubmit per prompt

Do not use "KYC passing service".

## 6. Security after KYC

Enable before large deposits:
- Binance Authenticator / Google Authenticator
- Passkey
- Anti-phishing code
- Withdrawal whitelist
- Device management

Never share:
- password
- SMS code
- 2FA code
- seed phrase
- private key

Binance staff will not DM you for codes.

## 8. Depositing USDT from outside

Most important: network must match.

USDT exists on:
- TRC20
- ERC20
- BNB Smart Chain
- Arbitrum

Same name, different networks. Wrong network = funds may not arrive.

Check:
- Asset = USDT
- Binance network selected
- Sending platform same network
- Full address
- Memo / Tag if required
- Min deposit
- Fee
- Small test first

## 9. First BTC buy

Trade → Spot → BTC/USDT

### Market order
Fills fast at current price.
Example: spend 100 USDT → Market Buy.

### Limit order
You set target price.
Example: BTC 80,000 now, you only buy at 78,000 → Limit 78000.

New users: small amount first, no leverage.
