## 1. What a rebate code actually is

### In one sentence
A rebate code (referral code / invite code) is a tag the exchange uses to identify which channel a user came from.

### How the money flows

```
You place an order
   ↓
Binance charges the standard fee (e.g. 0.10% on Spot)
   ↓
Part of that fee is normally allocated as referral channel commission
   ↓
Because you signed up with BNOFFICIAL, you occupy that referral slot yourself
   ↓
Binance returns that portion (40%) to your account
```

**The key point: Binance is not marking up your fee and refunding part of it. The fee is public and unchanged — the exchange is simply giving you back a share of its own revenue.**

|---|---|---|
| Referral / invite code | Channel tag entered at signup | You (you get the rebate) |
