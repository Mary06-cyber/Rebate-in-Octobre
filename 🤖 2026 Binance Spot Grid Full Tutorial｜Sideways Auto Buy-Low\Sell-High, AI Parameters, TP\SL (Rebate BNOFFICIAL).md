## 🟢 1. Which Market Regime Fits Grids

| Range/sideways | Frequent fills, small profits add up | Best for spot grid |

## 🟢 3. Core Parameters

| Parameter | Meaning | Beginner tip |
| :--- | :--- | :--- |
| Upper price | Highest sell zone | Based on recent range high; leave buffer |
| Lower price | Lowest buy zone | Based on recent support; leave buffer |
| Grid count | How many levels in range | Majors 10–20; more grids = smaller per-fill profit but more trades, fewer grids = bigger per-fill but fewer trades |
| Arithmetic/Geometric | Fixed price step or fixed ratio step | Small range arithmetic, large/high-price range geometric |
| Investment amount | Total grid capital | One grid strategy 10%–20% of tradable funds max |
| Trigger price | Start only when price reaches level | Use if you don’t want immediate start |
| Take-profit | Exit when overall profit target hit | Set above range for sideways systems |
| Stop-loss | Exit on broken range or max loss | Mandatory in one-way risk scenarios |

## 🟢 6. Beginner Mistakes

| Mistake | Consequence | Fix |
| :--- | :--- | :--- |
| Too narrow range | Hits bounds quickly, bot idles | Widen using ATR/recent high-low |
| Too many grids | Per-grid profit smaller than fees | Calculate net per-grid profit first |
| No stop-loss | Downtrend keeps buying into heavy bag | Overall stop or auto-stop below lower bound |
| Illiquid alt | Poor depth, slippage, wicks | Start with BTC/ETH/BNB/SOL |
| Treat AI as guarantee | Backtest ≠ live | Use AI as starting point, review manually |
