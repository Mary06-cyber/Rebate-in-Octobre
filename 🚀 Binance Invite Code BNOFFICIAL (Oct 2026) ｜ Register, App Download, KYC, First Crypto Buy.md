## 4. Do new users need KYC?

Yes.

All new users need **Verified** identity verification to use deposits, trades, and withdrawals. Without KYC the account is usually limited.

KYC steps:
1. Fill personal info
2. Select country/region
3. Upload supported ID
4. Take document photos
5. Face verification
6. Wait for review

Name, birth date and ID data must match the document exactly.

- wrong info
- name mismatch
- camera permission off
- dark environment
- expired document

Fix:
1. Match info with ID
2. Use clear original document

4. Bright environment
5. Update App
6. Resubmit per on-screen reason
