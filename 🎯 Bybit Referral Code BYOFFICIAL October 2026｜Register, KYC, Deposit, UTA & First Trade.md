## 🏦 6. Funding Account vs UTA

On-chain deposits usually arrive in the Funding Account first. It is used for deposits, withdrawals, some fiat and fund management.
The Unified Trading Account (UTA) is used for Spot, Spot Margin, Perpetual, Futures, Options and other supported products.

If USDT arrived but spot/contract page shows no balance, check whether it is still in Funding Account.
Transfer path:
Assets → Transfer → From Funding Account → To Unified Trading Account → choose USDT → enter amount → Confirm.
This is an internal transfer within the same Bybit account, not an on-chain withdrawal, so no blockchain network fee applies. Bybit also provides Deposit Route settings so future deposits can go to Funding, UTA or other supported accounts per configuration.
