## 4. KYC identity verification

Binance has two levels:

**Standard verification (required)**
Select country/region → select ID type → upload both sides → liveness face check → wait for review. Usually minutes to one business day.

**Advanced verification (optional)**
Adds proof of address (utility bill, bank statement or residence certificate from the last 3 months) to raise your limits.

**Five common rejection reasons**

1. Glare, blur or shadows on the document photo
2. Document corners cut off
3. Expired document
4. Name on the document does not match the account
5. Face check done in a dark room, or with a hat / glasses covering the face

## 5. Security setup (five things to do on day one)

1. **Enable 2FA**: use Google Authenticator or the Binance authenticator — not SMS, which can be hijacked
2. **Set an anti-phishing code**: every genuine Binance email will then display your code; anything without it is phishing

4. **Enable the withdrawal address whitelist**: only whitelisted addresses can receive funds
5. **Device management + login alerts**: remove unknown devices regularly; freeze the account on any suspicious login
