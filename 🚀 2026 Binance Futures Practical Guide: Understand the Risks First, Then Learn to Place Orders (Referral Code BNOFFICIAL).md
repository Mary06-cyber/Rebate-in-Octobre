## 📌 1. Futures Is Not "Guessing Up/Down"

| Direction-Only Problem | A Complete Trade Plan Should Include |
| :--- | :--- |
| Long if bullish, Short if bearish | Entry Plan |
| Only asks about leverage | Risk Plan (Stop Loss, max loss, liquidation distance) |
| No exit strategy | Exit Plan (Stop Loss, Take Profit, Partial Close) |

A qualified futures trade must have: entry rationale, invalidation price, max acceptable loss, position size, leverage, and fee/funding estimates.

## 📌 2. Spot vs Futures

| Type | Holding Nature | Common Elements | Risk Structure |
| :--- | :--- | :--- | :--- |
| Spot | Directly hold asset (e.g., buy BTC with USDT) | Spread, spot fee, network withdrawal fee | Price drawdown causes unrealized loss, but no liquidation from leverage |
| Futures | Price direction position without owning the asset | Long/Short, Margin, Leverage, Liquidation, Funding | Leverage amplifies PnL; can lose margin quickly and get liquidated |

## 📌 5. Define "Max Loss Per Trade" First

| Futures Capital | Suggested Max Loss Approach | Purpose |
| :--- | :--- | :--- |
| 1000 USDT | Set 10–20 USDT cap for small practice trades | Control total drawdown |
| 2000 USDT | Set 1%–2% cap based on strategy, not "feeling" | Calculate position size after SL distance |
| Any amount | Max loss → SL distance → Position Size | Never decide leverage first |

Formula: Position Size ≈ Max Loss ÷ (Entry − Stop Loss) ÷ Contract Size Factor; actual values per order page risk calculator.

## 📌 7. Long vs Short

| Direction | Expectation | Favorable Move | Pre-Open Checklist |
| :--- | :--- | :--- | :--- |
| Long | Profit from price rise | Breakout up, support hold | Entry, invalidation, SL, TP, max loss |
| Short | Profit from price drop | Breakdown, resistance hold | Same as above + watch funding & short squeeze |

Don't chase a big green candle for Long or big red candle for Short without checking liquidity and SL space.

## 📌 8. Position Size ≠ Margin

| Concept | Meaning | Common Mistake |
| :--- | :--- | :--- |
| Margin | Frozen account funds for open position | Visible but ≠ market exposure |
| Position Size | Actual nominal position value | 100 USDT margin at 10x = 1000 USDT nominal exposure |
| Actual Risk | Depends on distance to SL | High leverage + wide SL can be worse than low leverage + tight SL |

## 📌 9. Leverage ≠ Total Risk

| Same 10x, Different Risk | Reason |
| :--- | :--- |
| A: Tight SL, small size | Controllable actual loss |
| B: Wide SL, large size | Large nominal exposure, faster liquidation |
| C: High-volatility altcoin | Wicks, slippage, funding change outcomes |

Low leverage ≠ automatically safe; high leverage ≠ automatically fatal. Core: Max Loss × SL × Position Size.

## 📌 10. Isolated vs Cross

| Mode | Margin Scope | Advantage | Beginner Note |
| :--- | :--- | :--- | :--- |
| Isolated | Independent per position | Loss cap is clearer, won't eat whole account | Separate liquidation possible |
| Cross | Shared wallet available balance | Better resistance to small pullbacks | One bad trade can drag entire Futures wallet |

Start with Isolated small trades to understand "one position = one margin = one risk scope."

## 📌 11. 5 Data Points Before Opening

| Data | Function | Don't Size Up If Unclear |
| :--- | :--- | :--- |
| Entry Price | Calculate PnL, SL/TP distance | Average entry changes with add-ons |
| Position Size | Real nominal exposure | Check with leverage for margin |
| Leverage | Capital efficiency & liq speed | Never judge safety alone |
| Stop Loss | Active exit limit | Must be based on invalidation, not feeling |
| Liquidation Price | System forced close reference | Last resort only, NOT a substitute for SL |

## 📌 12. Mark Price vs Last Price

| Price Type | Use | Difference |
| :--- | :--- | :--- |
| Last Price | Most recent fill | Can be skewed by large orders/slippage |
| Mark Price | Used for liquidation, unrealized PnL | Smoother, reduces false liquidations |
| Index Price | Reference spot basket | Used for funding & basis |

## 📌 13. Market vs Limit Orders

| Type | Best For | Pros | Cons |
| :--- | :--- | :--- | :--- |
| Market | Fast entry/exit, liquid majors | Quick fill | Slippage in volatile moves |
| Limit | Planned price entry | Control fill price | May not fill if price doesn't reach |
| Stop/Conditional | Trigger to Market or Limit | Breakout or auto-SL | Requires correct trigger setup |

## 📌 14. Stop Loss Should NOT Be Placed at "Comfortable" Levels

| Wrong | Right |
| :--- | :--- |
| Place SL randomly just to limit loss to 20U | Find structural invalidation first, then measure distance |
| Fixed 1% SL for all coins | Adjust by volatility, S/R, contract size |
| Move SL further after loss to "wait for recovery" | If no new plan, don't expand risk; consider reducing size |

SL = active risk control; Liquidation = system forced close. Never confuse them.

## 📌 15. Take Profit Can Be Staged

| Stage | Action | Purpose |
| :--- | :--- | :--- |
| TP1 | Reduce at first target | Lock partial profit, reduce drawdown |
| TP2 | Reduce at second target | Let remainder ride trend |
| Partial Close | Close portion only | Keep position while lowering risk |
| Final Exit | Reverse signal or trailing stop | Avoid giving back profits |

## 📌 16. Risk/Reward Ratio

| Example | Calculation | Judgment |
| :--- | :--- | :--- |
| 20U SL, 60U target | 60÷20=3 | RR 1:3 |
| 50U SL, 50U target | 50÷50=1 | RR 1:1, needs high win rate |
| 10U SL, 10U target | 10÷10=1 | Plus fees may not be worth it |

Include SL distance, fees, funding, and slippage in net reward calculation.

## 📌 18. Don't Randomly Change Plan After Opening

| Emotional Behavior | Fix |
| :--- | :--- |
| Raise TP after small pump | Don't change targets without new structural evidence |
| Move SL further after dip | Re-evaluate only if invalidation changed, don't just "wait to break even" |
| Increase leverage after consecutive SLs | Pause, review, reduce size |
| Over-size after profit | Scale by rules, not excitement |

## 📌 19. Unrealized vs Realized PnL

| Type | When | Note |
| :--- | :--- | :--- |
| Unrealized PnL | Changes with Mark Price while open | Not locked in until close |
| Realized PnL | After partial/full close | Deduct fees & funding for net result |
| Fees/Funding | On open/close & holding through funding time | High-frequency or tight-SL strategies feel this most |

## 📌 22. Don't "Average Down to Save a Losing Trade"

| Wrong Averaging Chain | Result |
| :--- | :--- |
| Loss → Add → More Loss → Add More | Position Size balloons; recovery % needed shrinks but liquidation risk explodes |
| Unplanned averaging | Looks like lower avg price, actually increases risk |
| Cross-margin whole account to support | One mistake drags entire account |

If original trade is invalidated, exit per plan. Adding size must be a new strategy with new SL, size, and capital allocation.

## 📌 23. Emotional Trading Red Flags

| Common Trap | Alternative |
| :--- | :--- |
| Double next trade immediately after loss | Stop, review, restart at original risk limit |
| Chase Long on big green, Short on big red | Wait for pullback/retest, confirm trigger & SL |
| Raise leverage after consecutive SLs | Reduce size, lower leverage, practice on small trades |
| Full position after first profit | Scale per money management rules |
