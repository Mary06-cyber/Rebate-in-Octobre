## 8. Five common myths

**Myth 1: The invitee's rebate is deducted from the referrer's commission.**
No. Both come from the platform's own budget and do not offset each other.

**Myth 2: A signup alone counts as a valid invite and pays the bonus.**
No. KYC + deposit + trading threshold are usually required.

**Myth 3: The commission rate is fixed.**
No. It generally floats by tier/volume — "up to 50%" is the top tier.

**Myth 4: Existing users can add a referral code anytime.**
No. The relationship is created at signup. Retro-fitting has a strict window, and UID cannot be changed.

**Myth 5: Some tool can "force" a rebate or rewrite referral attribution.**
All scams. Only official support has that authority.
